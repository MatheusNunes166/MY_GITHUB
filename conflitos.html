Resolução de Conflitos

Como lidar com conflitos durante merges e pull requests

Conceitos Básicos Fluxo de Trabalho Resolução de Conflitos

1) Criando uma feature branch

git checkout -b feature/resolvendo-conflito

Crie um arquivo resolucao_conflito.md e documente com prints como você resolveu um conflito (antes/depois).

2) Merge com a branch main

# Certifique-se de estar na sua feature
git checkout feature/resolvendo-conflito
git fetch origin
git merge origin/main

Se não houver conflitos:

git push -u origin feature/resolvendo-conflito

Se houver conflitos:

<<<<<<< HEAD
(sua versão na branch)
=======
(versão que veio de origin/main)
>>>>>>> origin/main

3) Abrindo um Pull Request

  1. No GitHub, clique em Compare & pull request.
  2. Confirme a branch base e a branch de comparação.
